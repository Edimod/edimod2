What you need

A laptop or computer capable of booting from a USB drive and equipped with an x86 BIOS,2. A Windows-based device with the Rufus© program installed (we will use it to install this OS, which you can download from the website),This operating system was tested on a Samsung R530—don't worry, it's a laptop..

What’s next

If you have already downloaded the system from that website, make sure that it is in .iso format,(This guide has been updated for 2026; to ensure full compatibility, please install the version rufus-4.15.exe). Insert your USB drive into your device. Under the "Device" menu, select your USB flash drive. In the "Boot selection" section, choose our system (ISO) file. Select "MBR" and "BIOS" (these should be set automatically), then click "Start" and confirm all prompts by clicking "OK." .

What are the next steps after creating a bootable USB using Rufus©?

On device 2 (where you are installing the system), enter the BIOS—this is usually done by pressing keys like DEL, F2, or F8 (in my case, it was F2). In any case, the correct key will be indicated on the screen once you are in the BIOS. .

I’m in the BIOS nowww

Select the "Boot" tab and set the USB flash drive (containing the ISO file) as the first boot device; save your changes—in my case, this was done by pressing F10—and exit the BIOS. The laptop should then boot from our system..
